# Code of Conduct

Parmar AI is operated as a professional, security-conscious software project.

Participants in authorized discussions, reviews, and contributions are expected to communicate respectfully and focus on technical facts.

## Prohibited conduct

- harassment or threats
- doxxing or publication of personal information
- credential or secret sharing
- publication of private student data
- malicious code or intentionally compromised dependencies
- attempts to bypass access controls
- deliberate production disruption
- misrepresentation of affiliation with Parmar AI

The project maintainer may remove content, restrict participation, or terminate an authorized collaboration when necessary to protect people, data, or production systems.

Security vulnerabilities belong in SECURITY.md, not in public issue details.
