SawalNewton V1

1. Replace the contents of your GitHub repository with the contents of this folder.
2. Do NOT change or add Telegram tokens in the code. Keep existing Cloudflare secrets:
   TELEGRAM_BOT_TOKEN
   TELEGRAM_WEBHOOK_SECRET
   TELEGRAM_SETUP_SECRET
3. The existing D1 database is already referenced as sawalnewton-db / DB. Do not create a new database.
4. Let Cloudflare Workers Builds deploy the main branch.
5. Open https://YOUR-WORKER-URL/health
6. Open https://YOUR-WORKER-URL/db-test and confirm the tables are present.
7. In Telegram send /start to the SawalNewton bot and tap Start Test.

V1 includes:
- Telegram webhook
- SawalNewton Mini App
- Telegram WebApp authentication
- D1 users/questions/attempts/attempt_questions
- 10-question random Maths test
- 5-minute timer
- server-side scoring
- result screen
- Telegram result sharing
