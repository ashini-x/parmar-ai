SAWALNEWTON V1 — REPLACEMENT

Replace the contents of the current parmar-ai repository with this folder.

Before the first Cloudflare deployment:
1. Keep the existing Worker named parmar-ai.
2. Open `wrangler.jsonc` and replace `REPLACE_WITH_YOUR_D1_DATABASE_ID` with your existing `sawalnewton-db` Database ID.
3. Keep the existing Cloudflare D1 binding named DB pointing to sawalnewton-db.
4. Keep the existing Telegram secrets:
   TELEGRAM_BOT_TOKEN
   TELEGRAM_WEBHOOK_SECRET
   TELEGRAM_SETUP_SECRET

After deployment:
1. Open https://YOUR-WORKER-URL/db-test
2. Confirm it returns the D1 tables.
3. Open the SawalNewton bot and send /start.
4. Tap Start Test.

The test needs at least 10 active Maths questions. The supplied schemas/seed-dev.sql contains 10 temporary DEV questions if needed.

Do not commit Telegram tokens or other secrets.
