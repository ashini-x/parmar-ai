SAWALNEWTON V1.2 — CONTENT FACTORY

1. Replace your GitHub repository with this folder.
2. Keep the existing Cloudflare Telegram secrets.
3. Add a new Cloudflare Worker secret:
   ADMIN_SECRET
4. Deploy.
5. Open:
   https://YOUR-WORKER-URL/admin/content
6. Enter ADMIN_SECRET.
7. Upload a small PDF/TXT/CSV test source.
8. Set exam/tier/year/shift/subject correctly.
9. Let Gemini process it.
10. Inspect the staging queue.
11. Publish only the candidates you want in production.

DATABASE:
Run the CONTENT of:
schemas/migrations/0002_content_factory.sql
inside the D1 Console.

Do NOT paste the filename into the SQL console.

FIRST TEST:
Use a small source with roughly 5–20 questions.
Do not start with hundreds of pages.

The factory is designed to eliminate manual question transcription.
It does not remove the need to use legitimate, reusable source material.
