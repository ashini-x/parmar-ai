# v2.5.0 Admin Control Center Logic

v2.5.0 adds the founder/administrator observability and control layer on top of the stable v2.4.2 student experience.

## Admin principle

The dashboard is designed for a non-technical owner. It should answer five questions quickly:

1. Who is using Parmar AI?
2. Is the AI answering reliably?
3. How much AI usage/cost is being consumed?
4. What are students learning and struggling with?
5. Does anything require administrator action?

Technical implementation details remain available through the System/Activity views rather than being forced into the primary owner experience.

## Dashboard areas

- **Overview:** total/new/active/returning students, questions, success/failure, latency, queue backlog, daily/burst limit hits, alerts, top subjects/topics, quota distribution, most-active students and retention snapshots.
- **Students:** search, individual usage, estimated spend, recent questions, topics, learning signals, unlimited access, suspension and profile reset controls.
- **AI & Costs:** prompt/output/thought/tool-use/cached/total tokens, model attempts, cost estimates, retry cost, spend by thinking level, grounding, model/policy, seven-day trend and expensive requests.
- **Learning:** subjects, topics, question modes and repeated explicit-confusion topics.
- **Activity:** recent question stream with status, attempts, latency, tokens and estimated cost.
- **System:** runtime version, environment, model, location, thinking policy, dependency visibility, queue/Durable Object state and safe settings.
- **Access:** owner/admin/static allowlist visibility and D1 runtime unlimited-access overrides.
- **Audit:** administrator actions with actor, action, target and details.
- **Reports:** JSON export for offline Python/Matplotlib analysis.
- **Settings:** safe, read-only operational configuration visibility. Dangerous infrastructure and secrets remain in Cloudflare.

## AI token accounting

Gemini response usage metadata is recorded per model attempt. This includes prompt, candidate/output, thought/reasoning, tool-use and cached-content token counts when supplied by the API.

A single user question may require multiple model attempts. Each genuine attempt is stored with a queue attempt number and internal attempt number. Duplicate accounting is prevented with `UNIQUE(update_id, queue_attempt, attempt)`.

## Cost accounting

The application calculates estimated cost in integer micro-USD to avoid floating-point drift. The estimate is derived from configured input, cached-input and output/reasoning rates. The dashboard labels it **estimated spend**. Google Cloud billing remains authoritative.

The optional `AI_BUDGET_USD` value is an administrator-defined reporting threshold, not a live Google Cloud account balance.

## Real-time behavior

The dashboard refreshes its overview on a five-second interval. It is intentionally polling-based so the Worker remains simple and the dashboard stays independent from the student question-processing path.

## Student economics

The dashboard can show aggregate and per-user estimated AI cost. Admin/test accounts can be separated conceptually from ordinary traffic through privileged access status. The current build does not fabricate billing data or claim an exact cloud-billing balance.

## Quota visibility

The student quota remains 20 accepted AI questions per India calendar day by default, with a five-question/10-second burst safeguard. The dashboard surfaces daily-limit and burst-limit events and a daily quota distribution based on accepted question records.

## Security boundary

Dashboard actions require the existing protected admin session. Sensitive owner/admin identifiers are configuration data and are not stored in the public source repository. Owner and configured admins are protected from dashboard suspension.

## Reporting

`reports/generate_report.py` is offline-only. It consumes an exported Admin JSON snapshot and produces:

- `parmar-ai-founder-report.pdf`
- `daily_ai_summary.csv`
- `ai_spend.png`
- `ai_tokens.png`
- `SUMMARY.md`

Python is deliberately excluded from the Cloudflare Worker request path.
