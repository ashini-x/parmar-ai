# v2.5.2 Admin Access Controls Fix

v2.5.2 fixes the Students directory access-control UI.

## Effective access
The directory now applies the same server-side access sources as the runtime: bot owner ID, configured admin IDs, static unlimited IDs, and D1 runtime overrides.

## Protected accounts
Owner/admin accounts are shown as protected and cannot be suspended or revoked from the Students directory.

## Browser actions
Grant/revoke and suspend/unsuspend actions now pass quoted action names into `userAction()`.

## Error handling
Failed admin actions now display an actionable error rather than silently returning to the page.

## Quotas
No student quota policy changed: 20 accepted AI questions/day by default and 5 accepted questions/10 seconds for all accounts.
