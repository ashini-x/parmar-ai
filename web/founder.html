BRɅIN / FOUNDER

Ashini Gogoi

I’m the founder of BRɅIN. My work is focused on building software that can use private documents while keeping access permissions and source-page references intact.

Why I started BRɅIN

I started working on BRɅIN while building applications that needed to answer from real study material. With परमार्थAI, I saw that producing a response was only one part of the job: a learner also needed to trace it to the source and the original PDF page. As I thought about other products and workspaces, the same foundation kept coming up — document intake, OCR, page mapping, indexing, access checks and retrieval.

Rebuilding that foundation inside each application would repeat the same work and tie the knowledge system too closely to one product. I wanted a shared layer that could process documents, enforce the relevant access rules and return evidence, while each application kept control of its own users, model, prompts and final answer. That is the idea behind BRɅIN.

The gap I'm working on

I'm not trying to build another general-purpose chatbot. The problem I'm focused on is underneath the user experience: how a specialised application or private workspace can use its own documents, apply its own access rules and receive traceable evidence without having to assemble every part of document processing and retrieval itself. The initial use cases are our own learning products and workspaces; the broader direction is a reusable service that other applications can integrate.

What I'm building

BRɅIN Core handles document processing, permissions and retrieval. It returns selected passages with their original PDF page references; the connected application creates the final answer.

BRɅIN Core

Core currently uses private Google Cloud Storage, Google Cloud Vision OCR, Cloudflare Workers and Workflows, D1 and Cloudflare AI Search. The live retrieval service checks application and project permissions before returning evidence.

Connected applications

परमार्थAI is a live Telegram MVP for competitive-exam preparation, with follow-up questions and quizzes inside Telegram. BRɅIN Teachers is a separate workspace app with a deployed Operator Console for teachers, projects, collections and study PDFs. Its student-facing rollout is still in development.

Building in the open

I keep the two repositories public so the implementation and current development status can be inspected. Core lives in parmar-ai; Teachers is a separate consumer in brvin-teachers. The repositories are the best place to check what is implemented and what is still being worked on.

Where the product stands

The production retrieval provider is Cloudflare AI Search. Vertex AI embeddings and Qdrant Cloud are being evaluated separately and are not the production provider today. The voice-provider integration is also in development, not a shipped production feature.
