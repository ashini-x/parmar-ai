BRVIN / PLATFORM ARCHITECTURE

From private documents to verified context.

BRVIN separates knowledge operations from the applications that use them. One shared platform manages documents, permissions and retrieval. Each connected product keeps control of its users, model and experience.

01INGEST

Secure document intake

PDFs are uploaded resumably to private Google Cloud Storage. SHA-256 verification checks the source file, and Google Cloud Vision extracts text while preserving physical PDF page identity.

GOOGLE CLOUD STORAGE VISION OCR
02PROCESS

Page-aware processing

Cloudflare Workers and Workflows coordinate indexing, retrieval checks, retries and recovery. D1 records progress. A source becomes available only when its expected pages are indexed and checks pass.

WORKERS WORKFLOWS D1
03GOVERN

Permissioned retrieval

D1 is the authority for application identity, projects, source grants, readiness and quotas. The private retrieval service searches only authorised sources and validates page provenance before returning evidence.

PRIVATE BRVIN SERVICE AI SEARCH
04CONNECT

Applications own the answer

Trusted applications connect through private Cloudflare Service Bindings. BRVIN returns bounded passages and PDF page citations. The application owns end-user authentication, prompts, model generation and conversation state.
