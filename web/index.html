BRɅIN / PLATFORM ARCHITECTURE

From private documents to verified context.

BRɅIN handles the document and retrieval work shared by connected products. Each product keeps its own users, prompts, model and conversation experience.

01INGEST

Secure document intake

A PDF is uploaded to private Google Cloud Storage and checked against its SHA-256 fingerprint. Google Cloud Vision extracts the text while BRɅIN keeps the original PDF page numbers.

GOOGLE CLOUD STORAGE VISION OCR
02PROCESS

Page-aware processing

Cloudflare Workers and Workflows run the processing steps and handle retries. D1 records each source’s progress. A source is marked ready only after its expected pages are indexed and the required checks pass.

WORKERS WORKFLOWS D1
03GOVERN

Permissioned retrieval

D1 keeps the records for application identity, projects, source permissions, readiness and usage limits. Before returning passages, the private service checks that the requesting application is allowed to access the source.

PRIVATE BRɅIN SERVICE AI SEARCH
04CONNECT

Applications own the answer

Connected applications call BRɅIN over private Cloudflare Service Bindings. BRɅIN returns selected passages and their PDF page numbers. The application handles sign-in, prompts, answer generation and conversation history.
